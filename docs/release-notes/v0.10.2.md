A pre-release: o3-303 is a whole firmware for the Tracker hardware, and it replaces the unit's own software while it is installed.

**PERFORM KNOBS: ACCENT on the FILTER set, and the hold walk stays inside the set. These changes need more testing.** The host tests and the cross build pass, and this image went through the static release gate in the release CI. The hand test on a unit is the maintainer's to do.

**Projects saved by v0.10.0 or v0.10.1 load unchanged** (still format 3.0). Projects saved by v0.9.0 or earlier do not load.

The changes since v0.10.1. The whole list is in [docs/CHANGELOG.md](https://github.com/trak3r-os/o3-303/blob/@TAG@/docs/CHANGELOG.md).

## What changed

- **PERFORM KNOBS set 1 (FILTER): row 2 is ACCENT** instead of DECAY. A new project starts with it. DECAY is one hold away.
- **A project saved before keeps the rows it saved** (DECAY on row 2). Shift + F1 (FACTORY 1) gives it ENV MOD, ACCENT, CUTOFF and RESO.
- **Holding F5 to F8 and pressing Up or Down walks only the knobs of the set in use:**
  - FILTER: CUTOFF, RESO, ENV MOD, DECAY, ACCENT, ACC DECAY, TRACKING and FILTER FM.
  - MODDED: its NOTES and TONE knobs, then WAVE and TUNE (OSC, which no other set holds) and the MODS switch.
  - GROWL and TRACT: their eight knobs and their switch.
  - WOBBLE: the wobble's settings, the WOB switch, then the delay and the distortion.
  - With Shift it jumps to the set's next or previous family. VOLUME is on HOME only.

## Saved files

- **Projects:** format 3.0, as in v0.10.0 and v0.10.1. A project saved by v0.9.0 or earlier is still refused with PROJECT FROM AN OLDER O3-303.
- **Unit settings and MIDI bindings** (`system.o3s`) are not affected.

## What a unit has shown

- This image has not booted on a unit yet.
- Owed by hand: the walk of each set (F1 to F4 and TRACT; hold F5 to F8, then Up or Down, with and without Shift) and ACCENT on row 2 of a new project.

## Install, and the way back

Download `o3-303-@TAG@.ptf` and `SHA256SUMS`, then check the download with `sha256sum -c SHA256SUMS`.

Back up the whole card first, and keep the firmware you run now on your computer. Then follow [section 2 of the manual](https://github.com/trak3r-os/o3-303/blob/@TAG@/docs/MANUAL.md#2-install-it-and-go-back-to-the-stock-firmware): by the card with the hidden reset button, or over USB from a firmware with the console. The way back is the same section.

For the USB console, the image's CRC-32 is `@CRC32@`.
