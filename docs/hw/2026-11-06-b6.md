image on o3-sdk `ef6b1a0`, which brings the encoder curve, button repeat for a screen and the hook for a learned MIDI move. This page checks what a host test cannot: the real
buttons, pads, LEDs and display, a project written by an earlier image, and the render budget with the new layout.

goes on. Every other row runs by the console: `key`, `enc`, `state`, `leds`, `cpu`, `crash`, `log`, `version`, `files`, `reset`, `skin`.

the start state and restore exactly it. A source is connected to the line-in: leave it connected. An install loses the unsaved STATUS LED

`reset` drops them. No RECORD take, and no project saved: neither the app nor the console can delete what that writes. The kit's settings gain key 33 (ENCODER): `system.o3s` may
change when a Config row is written, and an older image skips the key. Record its hash at the start and the end, and say if it moved.
