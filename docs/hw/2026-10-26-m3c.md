## Finding, fixed: "Mix 0 %" that was not 0

From step 5 on, the round's CPU sat about 7 points above its start, idle included. The growl's Mix showed 0 % but was a residue of float encoder steps a hair above 0. `param_step` adds steps in float and clamps only below the minimum. So the growl never went idle and ran its whole path. Turning the Mix far below 0, so it clamps to exactly 0, brought idle back to 35.9 % and playing to 37.1 %.

Fix: the growl takes a Mix below 0.001 as 0 (`kMixOff`), and its test covers a 2.2e-8 residue. The same residue can keep any unit that bypasses itself at 0 running. The kit's `param_step` is track3r-os's code, so the root cause goes to the maintainer.
